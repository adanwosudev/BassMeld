# BassMeld

BassMeld is a high-performance, real-time orchestrator for event-driven data processing and streaming-data ingestion with concurrent task scheduling.

With BassMeld, you get a lightweight tool that stays out of your way.

**What you get**

- BassMeld is a high-performance, real-time
- orchestrator for event-driven data processing
- and streaming-data ingestion with concurrent

## Technology Stack

- rust

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/BassMeld.git`
2. `cd BassMeld`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure BassMeld, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
